Philosophy

思想

世界は、ずっと流れ続けている。
人も、働き方も、価値観も、
少しずつ形を変えていく。

変わることは、失うことじゃない。
流れの中で削ぎ落とされながら、
本当に大切なものだけが残っていく。

TDNMは、「徒然なるままに」という感覚を大切にしながら、
無理をせず、でも、誤魔化さず、
自分たちらしいスタンスで創ることを選び続けています。

整えることは、飾ることではなく、本質を見つけること。

ゆるく、生きる。でも、芯はまっすぐに。

What We Do

事業内容

想いを、社会に翻訳する。

TDNMは、単なる制作会社ではありません。「何を作るか」の前に、“本当は何を伝えたいのか”を整理するところから始めます。

01 / CONCEPT
コンセプト整理 / MVV設計
頭の中にある想いや感覚を、伝わる言葉へ整理します。理念・世界観・ブランドの軸を、一緒に言語化します。
02 / ARCHITECTURE
サービス構造化 / 事業整理
やりたいことが多すぎて整理できない。伝えたいことが散らかっている。そんな状態から、「誰に・何を・どう届けるか」を整えてしていきます。
03 / PROPOSAL
提案資料 / ブランド提案
ただ綺麗なだけでは終わらない。温度感・思想・空気感まで含めて、“伝わる提案”を設計します。
04 / CREATIVE
Web / ビジュアル制作
世界観を、視覚として表現する。ロゴ、Web、SNS、資料、ビジュアル。ブランドの空気感まで一貫して設計します。
05 / INTEGRATION
AI活用 / 業務導線整理
AIを使うことが目的ではなく、“人が本来やりたいこと”に集中できる状態をつくる。苦手な実務や整理を、無理のない形でサポートします。
How We Work

制作スタンス

TDNMは、「何を作るか」より、
「何を伝えたいか」を一緒に考えるチームです。

きれいなデザインより、正直な言葉。

目立つ表現より、残っていく意味。

流行を追うより、その人らしい“スタンス”を整える。

私たちは、完成品だけを作りたいわけではありません。
言葉になる前の想い。整理しきれていない熱量。まだ途中の構想。
そういう“流れの途中”から、一緒に伴走していきます。

Story

背景

仏教の精神に触れながら育ち、
「静かな芯」を大切にして生きてきました。

everything flows すべては流れ、変わり続ける。

その感覚を信じながら、ゆるく、でも、まっすぐに生きてきた人生。子育ても、仕事も、ものづくりも、コントロールしすぎない。

私たちは、“正解を押しつける”ためではなく、その人の中に、すでにある想いや価値を、一緒に見つけ、整え、社会へ届けるために存在しています。
